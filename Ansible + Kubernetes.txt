🔧 Ansible + Kubernetes — راهنمای جامع DevOps

    Ansible در لایه زیرین Kubernetes می‌نشیند (provisioning، bootstrap، hardening، runtime config) و در لایه بالا برای cross-cluster orchestration و Day-2 operations استفاده می‌شود. جایگزین kubectl/Helm/ArgoCD نیست — مکمل آن‌هاست.

🗺️ بخش ۱: جایگاه Ansible در اکوسیستم K8s
۱.۱ — مرز مسئولیت‌ها
text

┌──────────────────────────────────────────────────────────────┐
│ Layer 5: GitOps (ArgoCD/Flux)         ← Deploy declarative  │
│   کد اپلیکیشن، Kustomize/Helm، Git as truth                 │
├──────────────────────────────────────────────────────────────┤
│ Layer 4: Helm / Kustomize              ← Packaging           │
│   chart authoring، templating                                │
├──────────────────────────────────────────────────────────────┤
│ Layer 3: Ansible                       ← Day-2 Orchestration │
│   ✓ Cross-cluster operations                                 │
│   ✓ Bootstrap کلاستر (kubeadm)                               │
│   ✓ OS hardening، runtime config                             │
│   ✓ Install/upgrade components                               │
│   ✓ DR restore، maintenance workflows                        │
│   ✓ Backup automation                                        │
│   ✗ NOT for app deploys (از GitOps استفاده کن)              │
├──────────────────────────────────────────────────────────────┤
│ Layer 2: Terraform/Pulumi              ← Infrastructure      │
│   VPC، VM، LB، Managed K8s (EKS/GKE)                        │
├──────────────────────────────────────────────────────────────┤
│ Layer 1: kubectl                       ← Manual debug/ops    │
└──────────────────────────────────────────────────────────────┘

۱.۲ — چه چیزی Ansible را انتخاب می‌کند؟
سناریو	Ansible؟	چرا
ساخت EKS با Terraform	❌	Terraform state دارد
نصب kubeadm روی ۱۰ نود	✅	idempotent، بدون state، SSH-based
Deploy اپلیکیشن	❌	GitOps (ArgoCD) بهتر است
Upgrade همه master ها	✅	workflow ترتیبی
نصب Calico با values متفاوت per-cluster	✅	dynamic inventory
روز-۲: renew certificate ها	✅	scheduling + SSH
Backup etcd روی همه master ها	✅	cross-host orchestration
DR restore کلاستر	✅	چند-مرحله‌ای با چک
Node drain + upgrade + uncordon	✅	workflow با wait
ConfigMap/Secret management	⚠️	External Secrets بهتر است
Multi-cluster operations	✅	inventory-driven

قانون طلایی: Ansible برای چیزی که در Git نباید باشد (secret، host-specific، یکبار)، GitOps برای چیزی که باید در Git باشد (app manifests).

📄 Playbook 1: 01-bootstrap.yml — راه‌اندازی کامل از صفر
yaml

---
- name: Bootstrap Kubernetes cluster (HA-ready)
  hosts: all
  gather_facts: true
  become: true

  pre_tasks:
    - name: Verify OS is Ubuntu
      ansible.builtin.assert:
        that:
          - ansible_distribution == "Ubuntu"
          - ansible_distribution_major_version | int >= 22
        fail_msg: "Requires Ubuntu 22.04+"
      tags: [always, precheck]

    - name: Verify required ports are free
      ansible.builtin.wait_for:
        port: "{{ item }}"
        state: stopped
        timeout: 3
      loop: [6443, 10250, 2379, 2380]
      when: is_control_plane | default(false)
      ignore_errors: true
      tags: [precheck]

  roles:
    - role: common        # swap off, sysctl, modules, NTP, hosts
      tags: [os, common]
    - role: containerd    # install containerd + crictl + CNI plugins
      tags: [runtime]
    - role: kube-tools    # kubeadm/kubelet/kubectl
      tags: [k8s-tools]
    - role: k8s-ha        # keepalived + haproxy (فقط control_plane)
      when: is_control_plane | default(false) and keepalived_enabled | default(false)
      tags: [ha]

  post_tasks:
    - name: Verify kubelet is enabled
      ansible.builtin.systemd:
        name: kubelet
        enabled: true
      register: kubelet_svc

    - name: Display bootstrap status
      ansible.builtin.debug:
        msg:
          - "OS ready: {{ inventory_hostname }}"
          - "containerd: {{ containerd_version }}"
          - "kubeadm: {{ kubernetes_version }}"

- name: Initialize first control plane
  hosts: control_plane[0]
  gather_facts: false
  become: true
  tasks:
    - name: Check if already initialized
      ansible.builtin.stat:
        path: /etc/kubernetes/admin.conf
      register: admin_conf

    - name: Generate kubeadm-config
      ansible.builtin.template:
        src: kubeadm-config.yaml.j2
        dest: /etc/kubernetes/kubeadm-config.yaml
        mode: "0600"

    - name: Run kubeadm init
      ansible.builtin.command:
        cmd: kubeadm init --config=/etc/kubernetes/kubeadm-config.yaml --upload-certs
      register: kubeadm_init
      when: not admin_conf.stat.exists
      failed_when: >
        kubeadm_init.rc != 0 and
        "already initialized" not in kubeadm_init.stderr

    - name: Verify kubeadm init succeeded
      ansible.builtin.assert:
        that:
          - "'Your Kubernetes control-plane has initialized successfully' in kubeadm_init.stdout"
        fail_msg: "kubeadm init failed — check {{ kubeadm_init.stderr }}"
      when: not admin_conf.stat.exists

    - name: Copy admin.conf to root kube
      ansible.builtin.shell: |
        mkdir -p /root/.kube
        cp -f /etc/kubernetes/admin.conf /root/.kube/config
        chmod 600 /root/.kube/config
      changed_when: false

    - name: Get join command for control plane
      ansible.builtin.shell: |
        kubeadm token create --print-join-command
      register: join_cmd_cp
      changed_when: false

    - name: Get certificate key for CP join
      ansible.builtin.shell: |
        kubeadm init phase upload-certs --upload-certs | tail -1
      register: cert_key
      changed_when: false

    - name: Save join info
      ansible.builtin.set_fact:
        k8s_join_command: "{{ join_cmd_cp.stdout }}"
        k8s_cert_key: "{{ cert_key.stdout }}"

- name: Join remaining control planes
  hosts: control_plane[1:]
  gather_facts: false
  become: true
  tasks:
    - name: Skip if already joined
      ansible.builtin.stat:
        path: /etc/kubernetes/kubelet.conf
      register: kubelet_conf

    - name: Join as control plane
      ansible.builtin.command:
        cmd: >
          {{ hostvars[groups['control_plane'][0]].k8s_join_command }}
          --control-plane
          --certificate-key {{ hostvars[groups['control_plane'][0]].k8s_cert_key }}
          --apiserver-advertise-address={{ ansible_host }}
          --node-name={{ inventory_hostname }}
      when: not kubelet_conf.stat.exists
      register: join_cp

    - name: Wait for control plane to be ready
      ansible.builtin.command: kubectl get nodes
      delegate_to: "{{ groups['control_plane'][0] }}"
      register: cp_ready
      until: inventory_hostname in cp_ready.stdout
      retries: 30
      delay: 5
      changed_when: false

- name: Install CNI
  hosts: control_plane[0]
  gather_facts: false
  become: true
  tasks:
    - name: Install Calico operator
      kubernetes.core.k8s:
        kubeconfig: /etc/kubernetes/admin.conf
        state: present
        src: https://raw.githubusercontent.com/projectcalico/calico/{{ calico_version }}/manifests/tigera-operator.yaml
      register: calico_op
      retries: 3
      delay: 10

    - name: Wait for tigera-operator available
      kubernetes.core.k8s_info:
        kubeconfig: /etc/kubernetes/admin.conf
        kind: Deployment
        namespace: tigera-operator
        name: tigera-operator
        wait: true
        wait_condition:
          type: Available
          status: "True"
        wait_timeout: 300

    - name: Create Calico installation
      kubernetes.core.k8s:
        kubeconfig: /etc/kubernetes/admin.conf
        state: present
        template: calico-custom.yaml.j2

    - name: Wait for all calico pods
      kubernetes.core.k8s_info:
        kubeconfig: /etc/kubernetes/admin.conf
        kind: Pod
        namespace: calico-system
        wait: true
        wait_condition:
          type: Ready
          status: "True"
        wait_timeout: 600

- name: Join worker nodes
  hosts: workers
  gather_facts: false
  become: true
  tasks:
    - name: Skip if already joined
      ansible.builtin.stat:
        path: /etc/kubernetes/kubelet.conf
      register: kubelet_conf

    - name: Join as worker
      ansible.builtin.command:
        cmd: >
          {{ hostvars[groups['control_plane'][0]].k8s_join_command }}
          --node-name={{ inventory_hostname }}
      when: not kubelet_conf.stat.exists

    - name: Label worker nodes
      kubernetes.core.k8s:
        kubeconfig: /etc/kubernetes/admin.conf
        kind: Node
        name: "{{ inventory_hostname }}"
        state: patched
        definition:
          metadata:
            labels: "{{ node_labels }}"
      delegate_to: "{{ groups['control_plane'][0] }}"

- name: Final verification
  hosts: control_plane[0]
  gather_facts: false
  become: true
  tasks:
    - name: All nodes Ready
      ansible.builtin.command:
        cmd: kubectl get nodes --no-headers
      register: nodes_out
      changed_when: false
      failed_when: >
        nodes_out.stdout_lines | reject('search', 'Ready') | list | length > 0

    - name: Display cluster status
      ansible.builtin.debug:
        msg: "{{ nodes_out.stdout_lines }}"

📄 Playbook 2: 02-add-node.yml — اضافه کردن نود جدید
yaml

---
- name: Prepare and join new worker node
  hosts: "{{ target_node | default('new_worker') }}"
  gather_facts: true
  become: true
  vars:
    join_endpoint: "{{ hostvars[groups['control_plane'][0]].ansible_host }}"

  roles:
    - role: common
    - role: containerd
    - role: kube-tools

  tasks:
    - name: Get fresh join token from control plane
      ansible.builtin.command: kubeadm token create --print-join-command
      delegate_to: "{{ groups['control_plane'][0] }}"
      register: join_cmd
      changed_when: false

    - name: Join cluster
      ansible.builtin.command:
        cmd: "{{ join_cmd.stdout }} --node-name={{ inventory_hostname }}"
      register: join_out
      when: not (join_out is defined)

    - name: Wait for node to register on API
      ansible.builtin.command: kubectl get node {{ inventory_hostname }}
      delegate_to: "{{ groups['control_plane'][0] }}"
      register: check
      until: check.rc == 0
      retries: 30
      delay: 5
      changed_when: false

    - name: Wait for node Ready condition
      ansible.builtin.command:
        cmd: >
          kubectl get node {{ inventory_hostname }}
          -o jsonpath='{.status.conditions[?(@.type=="Ready")].status}'
      delegate_to: "{{ groups['control_plane'][0] }}"
      register: ready
      until: ready.stdout == "True"
      retries: 60
      delay: 5
      changed_when: false

📄 Playbook 3: 03-upgrade.yml — ارتقای rolling همه نودها
yaml

---
# Phase 1: Pre-upgrade checks
- name: Pre-upgrade validation
  hosts: control_plane[0]
  gather_facts: false
  become: true

  tasks:
    - name: All nodes Ready
      ansible.builtin.command: kubectl get nodes --no-headers
      register: nodes
      changed_when: false
      failed_when: nodes.stdout_lines | reject('search', 'Ready') | list | length > 0

    - name: Backup etcd before upgrade
      ansible.builtin.include_role:
        name: etcd-backup
      vars:
        backup_reason: "pre-upgrade-{{ new_version | default('1.32.0') }}"

    - name: Check API deprecations
      kubernetes.core.k8s_info:
        kubeconfig: /etc/kubernetes/admin.conf
        api_version: apps/v1
        kind: Deployment
      register: deploys

    - name: Verify kubeadm target available in local repo
      ansible.builtin.command:
        cmd: apt-cache madison kubeadm | grep "{{ new_version }}"
      register: kubeadm_avail
      changed_when: false
      failed_when: kubeadm_avail.stdout == ""

    - name: Log upgrade start
      ansible.builtin.debug:
        msg: "Upgrading {{ kubernetes_version }} → {{ new_version }}"

# Phase 2: First control plane — full apply
- name: Upgrade first control plane (kubeadm upgrade apply)
  hosts: control_plane[0]
  become: true
  gather_facts: false

  tasks:
    - name: Upgrade kubeadm package
      ansible.builtin.apt:
        name: "kubeadm={{ new_version }}-1.1"
        state: present
        allow_change_held_packages: true
        update_cache: false

    - name: kubeadm upgrade plan
      ansible.builtin.command: kubeadm upgrade plan
      register: plan
      changed_when: false

    - name: Fail if plan has errors
      ansible.builtin.fail:
        msg: "Upgrade plan shows issues: {{ plan.stderr }}"
      when: "'ERROR' in plan.stderr"

    - name: Apply upgrade
      ansible.builtin.command:
        cmd: kubeadm upgrade apply {{ new_version }} --yes
      register: apply
      failed_when:
        - apply.rc != 0
        - "'already at the latest' not in apply.stdout"

    - name: Drain control plane
      kubernetes.core.k8s_drain:
        kubeconfig: /etc/kubernetes/admin.conf
        name: "{{ inventory_hostname }}"
        drain_timeout: 300s
        ignore_daemonsets: true
        delete_emptydir_data: true
        force: true
      delegate_to: "{{ inventory_hostname }}"
      ignore_errors: true

    - name: Upgrade kubelet & kubectl
      ansible.builtin.apt:
        name:
          - "kubelet={{ new_version }}-1.1"
          - "kubectl={{ new_version }}-1.1"
        state: present
        allow_change_held_packages: true

    - name: Restart kubelet
      ansible.builtin.systemd:
        name: kubelet
        state: restarted
        daemon_reload: true

    - name: Uncordon node
      kubernetes.core.k8s_drain:
        kubeconfig: /etc/kubernetes/admin.conf
        name: "{{ inventory_hostname }}"
        state: uncordon

    - name: Wait for Ready
      kubernetes.core.k8s_info:

  hosts: control_plane

          --cert=/etc/kubernetes/pki/etcd/server.crt
          --key=/etc/kubernetes/pki/etcd/server.key
      environment:
        ETCDCTL_API: "3"
      register: snap

    - name: Verify snapshot
      ansible.builtin.command:
        cmd: etcdctl snapshot status {{ backup_file }} -w json
      environment:
        ETCDCTL_API: "3"
      register: snap_status
      changed_when: false

    - name: Parse status
      ansible.builtin.set_fact:
        snap_size: "{{ (snap_status.stdout | from_json).totalSize | int }}"
        snap_keys: "{{ (snap_status.stdout | from_json).totalKey | int }}"

    - name: Fail if snapshot too small
      ansible.builtin.fail:
        msg: "Snapshot too small ({{ snap_size }} bytes) — likely corrupt"
      when: snap_size < 1024

    - name: Copy off-node (to bastion)
      ansible.builtin.fetch:
        src: "{{ backup_file }}"
        dest: "{{ backup_dir }}/remote/{{ inventory_hostname }}/"
        flat: true

    - name: Prune old backups (> {{ etcd_backup_retention_days }}d)
      ansible.builtin.find:
        paths: "{{ backup_dir }}"
        patterns: "etcd-*.db"
        age: "{{ etcd_backup_retention_days }}d"
      register: old
      delegate_to: "{{ item }}"
      loop: "{{ groups['control_plane'] }}"

    - name: Remove old snapshots
      ansible.builtin.file:
        path: "{{ item.path }}"
        state: absent
      loop: "{{ old.results | map(attribute='files') | flatten }}"

---
- name: Restore etcd from snapshot
  hosts: control_plane
  become: true
  gather_facts: false
  vars_prompt:

      register: snap
      delegate_to: "{{ groups['control_plane'][0] }}"
      run_once: true

      ansible.builtin.fail:
        msg: "Snapshot not found: {{ snapshot_file }}"
      when: not snap.stat.exists

    - name: Stop kubelet on all control planes
      ansible.builtin.systemd:
        name: kubelet
        state: stopped

    - name: Stop etcd (via crictl)
      ansible.builtin.shell: |
        ETCD_CONTAINER=$(crictl ps --name etcd -q)
        [ -n "$ETCD_CONTAINER" ] && crictl stop "$ETCD_CONTAINER" || true
      changed_when: false
      ignore_errors: true

      ansible.builtin.command:
        cmd: mv /var/lib/etcd /var/lib/etcd.broken-{{ ansible_date_time.epoch }}

      ignore_errors: true

        path: /var/lib/etcd
        state: directory
        mode: "0700"

      ansible.builtin.copy:
        src: "{{ snapshot_file }}"
        dest: /tmp/etcd-restore.db
        mode: "0600"

      delegate_to: "{{ inventory_hostname }}"

    - name: Build restore args per node
      ansible.builtin.set_fact:
        peer_url: "https://{{ ansible_host }}:2380"
        initial_cluster: >-
          {%- set items = [] -%}
          {%- for h in groups['control_plane'] -%}
            {%- set ip = hostvars[h].ansible_host -%}
            {%- set _ = items.append(h + '=https://' + ip + ':2380') -%}
          {%- endfor -%}
          {{ items | join(',') }}

    - name: Restore etcd
      ansible.builtin.command:
        cmd: >
          etcdctl snapshot restore /tmp/etcd-restore.db
          --data-dir=/var/lib/etcd
          --name={{ inventory_hostname }}
          --initial-cluster={{ initial_cluster }}
          --initial-advertise-peer-urls={{ peer_url }}
          --initial-cluster-token=k8s-etcd-restore
          --initial-cluster-state=new
      environment:
        ETCDCTL_API: "3"

    - name: Fix ownership
      ansible.builtin.file:
        path: /var/lib/etcd
        state: directory
        owner: root
        group: root
        recurse: true

    - name: Start kubelet
      ansible.builtin.systemd:
        name: kubelet
        state: started

    - name: Wait for API Server
      ansible.builtin.wait_for:
        host: "{{ ansible_host }}"
        port: 6443
        timeout: 300

    - name: Verify etcd health
      ansible.builtin.command:
        cmd: >
          etcdctl endpoint health
          --cluster
          --endpoints=https://127.0.0.1:2379
          --cacert=/etc/kubernetes/pki/etcd/ca.crt
          --cert=/etc/kubernetes/pki/etcd/server.crt
          --key=/etc/kubernetes/pki/etcd/server.key
      environment:
        ETCDCTL_API: "3"
      register: health
      until: health.rc == 0
      retries: 30
      delay: 10

    - name: Show health
      ansible.builtin.debug:

۷.۲ — 09-health-check.yml
yaml

---
- name: Cluster health check
  hosts: control_plane[0]
  gather_facts: false
  become: true

  tasks:
    - name: All nodes Ready
      kubernetes.core.k8s_info:
        kubeconfig: /etc/kubernetes/admin.conf
        kind: Node
      register: nodes
      failed_when: >
        nodes.resources | selectattr('status.conditions',
          'match', 'type:Ready') | list | length == 0

    - name: Unhealthy pods
      kubernetes.core.k8s_info:
        kubeconfig: /etc/kubernetes/admin.conf
        kind: Pod
        namespace: kube-system
      register: sys_pods

    - name: Assert
      ansible.builtin.assert:
        that:
          - sys_pods.resources | selectattr('status.phase', 'ne', 'Running') | selectattr('status.phase', 'ne', 'Succeeded') | list | length == 0
        fail_msg: "System pods unhealthy"

    - name: etcd health
      ansible.builtin.command:
        cmd: >
          etcdctl endpoint health --cluster
          --endpoints=https://127.0.0.1:2379
          --cacert=/etc/kubernetes/pki/etcd/ca.crt
          --cert=/etc/kubernetes/pki/etcd/server.crt
          --key=/etc/kubernetes/pki/etcd/server.key
      environment:
        ETCDCTL_API: "3"
      register: etcd
      failed_when: "'unhealthy' in etcd.stdout"

    - name: readyz
      ansible.builtin.command:
        cmd: kubectl get --raw=/readyz
      register: readyz
      failed_when: readyz.stdout != "ok"

    - name: Summary
      ansible.builtin.debug:
        msg:
          - "✅ nodes: {{ nodes.resources | length }}"
          - "✅ system pods: {{ sys_pods.resources | length }}"
          - "✅ etcd: healthy"
          - "✅ apiserver: readyz ok"

⚠️ بخش ۸: Anti-Patterns (چه کاری نکنیم)
Anti-Pattern	چرا بد	جایگزین
Ansible برای deploy app	State ندارد، rollback سخت	ArgoCD/Flux
Ansible برای هر config تغییر	Git نمی‌بیند	ConfigMap + Git
k8s module برای scale روزانه	drift می‌سازد	HPA + Git
Ansible در cluster برای DR	اگر cluster خراب، Ansible هم خراب	Ansible runner خارجی
shell: kubectl apply	idempotent نیست، خطا نمی‌گیرد	kubernetes.core.k8s
Secret در Ansible vars	leak در logs	Vault/ESO
یک playbook چند-هزار-خطی	غیرقابل نگهداری	roles + includes
--forks=50 روی apiserver	throttle	--forks=10 + serial
